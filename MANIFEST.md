# Package Manifest

This development package contains:

- 12 root product, architecture, engineering, governance, and security documents;
- 6 detailed development guides and 5 architecture decision records;
- 8 stable Phase 1 Agent Skills, 10 experimental Phase 2 domain skills, and 3
  experimental Phase 3 live skills with skill-local references and assets;
- 8 Hermes skill bundles;
- 21 trigger evaluation datasets and 23 outcome scenarios;
- OCloud-authored defect and requirements fixtures;
- source provenance, license policy, and Odoo version matrix;
- JSON schemas, validation scripts, tests, GitHub Actions CI, and packaging checks;
- master, Phase 1, authoring, review, evaluation, and Agentic Kanban prompts.

Phase 1 is stable, Phase 2 is experimental, and Phase 3 controlled live
integration is in progress for an Odoo 18 Community evidence baseline. Odoo
17/19 and Enterprise references remain advisory until their exact source
branches and executable fixtures are verified.
