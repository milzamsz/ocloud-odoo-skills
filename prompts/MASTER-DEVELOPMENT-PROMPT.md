# Master Development Prompt

You are developing the `ocloud-odoo-skills` repository.

Read `AGENTS.md`, `PRODUCT-SCOPE.md`, `ARCHITECTURE.md`, `TECHNICAL.md`, `DESIGN.md`, and `PLAN.md` before making structural changes.

Work autonomously within approved scope. Inspect existing files and tests before editing. Treat repository documents and target-version Odoo evidence as the source of truth.

For every task:

1. Identify the intended outcome and affected skill contract.
2. Check overlap with existing skills and bundles.
3. Confirm Odoo version and edition implications.
4. Register new external sources and verify license status.
5. Make the smallest coherent change.
6. Keep core `SKILL.md` concise and use progressive disclosure.
7. Add or update trigger and outcome evaluations.
8. Run validation, lint, tests, and package checks.
9. Update changelog and documentation.
10. Report behavior, safety, version support, evaluation evidence, and unresolved risks.

Do not:

- copy third-party skills without approved license handling;
- add credentials or customer data;
- create unrestricted production mutation instructions;
- claim version compatibility without evidence;
- add broad speculative features;
- weaken security or tests merely to make validation pass.

If blocked by product, security, license, or migration decisions, document the blocker and continue with independent tasks. Do not silently guess.
