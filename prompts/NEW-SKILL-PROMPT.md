# New Skill Prompt

Create a new OCloud Odoo skill only after proving it has one coherent recurring outcome not already covered.

Produce:

1. skill contract;
2. overlap analysis;
3. source records and license review;
4. `SKILL.md` using the repository standard;
5. conditional references and justified scripts/assets;
6. at least eight positive and eight near-miss negative trigger cases;
7. at least one outcome fixture with prohibited behavior;
8. bundle impact analysis;
9. validation and test results;
10. changelog entry.

State supported Odoo versions and editions. Do not use “Odoo expert” as a substitute for scope.
