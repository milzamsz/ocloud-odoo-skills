# Skill Review Prompt

Review the selected skill as a production procedural artifact.

Evaluate:

- task coherence and overlap;
- trigger description precision and recall;
- progressive disclosure;
- version and edition safety;
- source authority and licensing;
- Odoo correctness;
- state-changing and script risk;
- output contract and verification;
- trigger and outcome evaluation quality;
- token and operational overhead;
- compatibility with Hermes tap packaging.

Return blockers, material findings, optional improvements, and a prioritized remediation plan. Do not edit files unless explicitly requested.
