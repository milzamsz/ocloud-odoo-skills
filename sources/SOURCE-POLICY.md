## Third-party content

Every external source retains its own license. A URL in the source registry is not permission to copy its text, scripts, templates, or code.

Use modes:

- **Authoritative reference**: link and paraphrase verified facts.
- **Inspiration**: study the problem and write an original solution.
- **Test corpus**: use a pinned public fixture according to its license.
- **Derivative inclusion**: permitted only after explicit license review, attribution, and compatibility approval.
- **Prohibited copy**: proprietary, unclear, or incompatible material must not enter the repository.

Odoo Enterprise source must never be redistributed through this repository.


## Source authority fields

Every source record must include:

- `id`
- `name`
- `url`
- `authority_tier`
- `usage`
- `license_status`
- `odoo_versions`
- `notes`

`last_reviewed` must be recorded per source. Existing records may temporarily inherit the
top-level `review_date`; new or materially re-reviewed records must set `last_reviewed`
directly. Use an ISO `YYYY-MM-DD` date.

No skill may claim a source as authoritative merely because it is popular or comprehensive.
