# Attribution and Influence Log

This repository is designed as an original OCloud synthesis. Public repositories listed in `SOURCES.yaml` inform problem discovery, taxonomy, and evaluation ideas. Their content must not be copied merely because it is technically convenient.

For every material influence, a pull request should state:

- source record ID;
- concept learned;
- authoritative verification performed;
- whether any text or code was reused;
- license and attribution treatment;
- evaluation demonstrating value.
